# Seneca-Energy-Hackathon
Microgrid opportunity mapping tool - Seneca Hackathon 2026

## Problem
Critical facilities (hospitals, fire stations, 
community centers) are vulnerable during power outages. 
Utilities lack a clear tool to identify where microgrids 
would have the most impact.

## Solution
A GIS-based scoring tool that ranks critical facilities 
in Peel Region by microgrid viability using:
- Outage history and risk
- Solar potential
- Facility criticality

## Tech Stack
