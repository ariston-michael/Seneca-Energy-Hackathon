# Raw Data Files

These files are NOT committed to GitHub due to size limits (>100MB).
Download them and place in this folder before running the scoring script.

| File | Source | Description |
|------|--------|-------------|
| odhf_v1.csv | Statistics Canada | Healthcare facilities across Canada |
| solarto-map - 4326.csv | Toronto Open Data | Solar potential per building rooftop |
| annual-energy-consumption-data-2024.xlsx.xlsx | NRCan | Building energy consumption Ontario |
| Renewable Energy Installations 2026.csv | Ontario Data | Existing renewable installations |
| 98-401-X2021021_English_CSV_data.csv | Statistics Canada | Census demographic data |

Run the scoring script after placing files here:
python scoring/process_facilities.py
